Qué es

Una IA que es tuya, no de un tercero

DEVMARK AI es la plataforma privada de IA de DEVMARK: un modelo propio, una API conocida y tus documentos como fuente de respuestas.

Privada

El modelo corre en un servidor de DEVMARK con Ollama. Lo que preguntas no se envía a terceros.

Compatible con OpenAI

Misma API de chat y mismos SDK. Si tu app ya usa OpenAI, solo cambias la dirección base y la key.

Con tu propio conocimiento

Sube tus documentos y las respuestas salen de tu información, indicando de dónde la sacó.

Un modelo que corre en servidores propios, se conecta como cualquier API y responde con lo que sabe tu empresa.

Cómo funciona

Tres pasos para conectarla

  1. 1

    Paso 1: Crea una aplicación y su key

    En el dashboard, una API key por aplicación, con límite por minuto, permisos y expiración. Se muestra una sola vez.

  2. 2

    Paso 2: Conéctala cambiando la base_url

    Tu código de OpenAI sigue igual: apunta a https://ai.devmarkpe.com/v1 y usa tu nueva key.

  3. 3

    Paso 3: Responde con tu conocimiento

    Sube documentos de texto, .md o .pdf a la aplicación. Cada respuesta usa los fragmentos relevantes y cita sus fuentes.

Qué incluye

Todo para integrar IA en tus aplicaciones

API tipo OpenAI

POST /v1/chat/completions y GET /v1/models. Funciona con los SDK de OpenAI cambiando solo la dirección.

API keys por aplicación

Cada app con su límite por minuto, permisos y expiración. Puedes revocar o regenerar una key con periodo de gracia.

Conocimiento (RAG)

La IA responde con tus documentos, con búsqueda de texto completo en español, y devuelve las fuentes usadas.

Herramientas

Consulta datos reales de tablas, APIs y páginas web, con credenciales cifradas y sin acceso a la red interna.

Playground

Chatea con el modelo desde el dashboard, con o sin documentos, sin API key ni código.

Uso y logs sin prompts

Peticiones, tokens, latencia y errores por app, key y modelo, sin guardar lo que se pregunta ni lo que se responde.

Para desarrolladores

Conéctala en minutos

Compatible con los SDK de OpenAI: solo cambia la dirección base. La key va únicamente en el backend de cada aplicación.

curl https://ai.devmarkpe.com/v1/chat/completions \
  -H "Authorization: Bearer $DEVMARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"llama3.2:1b","messages":[{"role":"user","content":"Hola"}]}'
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.devmarkpe.com/v1",
  apiKey: process.env.DEVMARK_API_KEY, // solo en el backend
});

const r = await client.chat.completions.create({
  model: "llama3.2:1b",
  messages: [{ role: "user", content: "Hola" }],
});
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.devmarkpe.com/v1",
    api_key=os.environ["DEVMARK_API_KEY"],  # solo en el backend
)

r = client.chat.completions.create(
    model="llama3.2:1b",
    messages=[{"role": "user", "content": "Hola"}],
)

Dirección base: https://ai.devmarkpe.com/v1

Seguridad

Privada de verdad

Keys con huella

Solo se guarda el hash de cada key (HMAC-SHA256) y su prefijo visible. Una API key no da acceso al dashboard.

2FA en el administrador

Verificación en dos pasos (TOTP) con códigos de recuperación de un solo uso.

Logs sin prompts

Los registros no guardan lo que se pregunta ni lo que se responde.

Secretos cifrados

Las credenciales de las herramientas se guardan cifradas y el dashboard nunca las devuelve.

Modelo fuera de Internet

Ollama, FastAPI y la base de datos no son accesibles desde fuera: todo entra por HTTPS con límites por IP.

Bloqueo de accesos

Tras 5 intentos fallidos de inicio de sesión el acceso se bloquea.

Preguntas frecuentes

Lo que suelen preguntar

¿Qué modelo usa?

Hoy usa llama3.2:1b, ejecutado con Ollama. Es un modelo compacto, pensado para un uso ligero. Las respuestas llegan completas, sin streaming.

¿Dónde corre y se envían mis datos a terceros?

El modelo corre en un servidor de DEVMARK y no es accesible desde Internet. Las preguntas no se envían a terceros para generar la respuesta. La base de datos (PostgreSQL en Supabase) guarda usuarios, aplicaciones, huellas de las keys, métricas y los documentos de conocimiento que subas.

¿Qué se guarda de lo que escribo?

Cada petición deja una fila con el endpoint, el modelo, los tokens, el tiempo y el estado. Los logs no guardan los prompts ni las respuestas.

¿Cómo la conecto a mi aplicación?

Con los SDK de OpenAI, cambiando la base_url a https://ai.devmarkpe.com/v1 y usando la API key de tu aplicación. La key va solo en el backend, nunca en el navegador ni en una app pública.

¿Cómo la conecto con un agente de IA?

Pídele a tu agente (Claude Code, Cursor, ChatGPT…) «conecta esta app a DEVMARK AI siguiendo https://ai.devmarkpe.com/llms.txt». Esa guía pública explica la URL, el modelo, ejemplos, errores y reglas de seguridad.

¿Y si una key se filtra?

La revocas o la regeneras desde el dashboard. Al regenerar, la anterior puede seguir funcionando 0 horas, 24 horas o 7 días para que cambies la key sin cortes.

¿Puedo probarla sin escribir código?

Sí. El Playground del dashboard permite chatear con el modelo, con o sin los documentos de una aplicación.

¿Cuánto cuesta?

Depende de lo que necesites. Cuéntale tu caso a un asesor y te orienta.
